以下はリポジトリの変更から補完した履歴です。日付はコミット日で、公開日とは異なる場合があります。

- 2026-10-24
    - トップページや番組ページの表示設定を変更する操作には、JavaScriptが必要になりました
    - トップページの日付移動リンクの表示には、JavaScriptが必要になりました
    - rss2.php の取得期間を最大14日間に制限。`days` は1以上の整数で指定してください
    - rss.php の `callback` によるJSONP出力と `lastupdate` による絞り込みを廃止
- 2026-10-23
    - rss2.php の `callback` によるJSONP出力を廃止
    - rss.php の `count` による取得件数の指定が反映されない問題を修正。未指定または0以下の場合は最大500件を返します
    - JSON APIの `ProgramByCount` では、単一の `TID` の指定が必須になりました
- 2026-10-22
    - データ取得APIの `TitleLookup` で、一度に指定できる `TID` を最大100件に変更。`TID=*` ではTIDの一覧のみ取得できます。タイトルの詳細は100件以下に分けて取得してください
    - `TitleLookup` の `Title` パラメータによる検索への対応を終了
    - JSON APIの番組情報取得で `UserInfo` の指定が正しく参照されない問題を修正
    - 放送時間の編集で日付の書式が正しくないとき、エラーメッセージに入力内容を表示するように修正
